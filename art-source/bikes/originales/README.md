# Berlin Quest — Bike Pack 01 (recortes corregidos)

4 modelos originales, separados mediante máscara de transparencia por componente; no por cuadrantes. Cada PNG conserva la bicicleta completa y el fondo transparente.

Estos son **assets visuales** de alta resolución, no sustituciones verificadas dentro de Phaser. Claude debe inspeccionar nombres de textura, escala, anclaje y profundidad antes de integrarlos. Usar solo una bicicleta de prueba y conservar fallback procedural. No redimensionar los originales: generar copias optimizadas aparte con nearest-neighbor o redibujado a resolución objetivo para pixel art.
